# Hotel Aurelia

Eine moderne, responsive Hotel-Webseite als fiktives Portfolio-Projekt, entwickelt mit HTML, CSS und JavaScript.

🌐 **[Live-Demo ansehen](https://fasi2706.github.io/hotel-aurelia/)**

## Über das Projekt

Hotel Aurelia ist eine beispielhafte Webseite für ein luxuriöses Hotel. Ziel des Projekts war es, ein elegantes Design mit übersichtlicher Navigation, ansprechenden Bildern und interaktiven Funktionen zu verbinden.

Die Webseite wurde für Desktop, Tablet und Smartphone gestaltet.

## Funktionen

- Responsive Navigation mit mobilem Menü
- Startseite mit großem Hotelbild
- Übersicht über drei Zimmerkategorien
- Wellness- und Spa-Bereich
- Bildergalerie mit vergrößerbarer Bildansicht
- Kontaktformular mit Demo-Bestätigung
- Optimierte Bilder für schnellere Ladezeiten

## Verwendete Technologien

- **HTML5** – Struktur und Inhalte
- **CSS3** – Design, Layout und responsive Darstellung
- **JavaScript** – Interaktive Galerie, Navigation und Formular
- **GitHub Pages** – Veröffentlichung der Webseite

## Hinweis

Hotel Aurelia ist ein fiktives Hotel. Die Webseite dient ausschließlich zu Demonstrationszwecken. Das Kontaktformular versendet keine echten Nachrichten und es können keine Zimmer gebucht werden.
